# 统计信息实时时钟

中文完整和精简统计信息会在开头显示不带标签的 `HH:mm:ss`，例如
`21:08:05 1920x1080 60.00 FPS HEVC 网络: 2 ms (波动: 1 ms) 丢包率: 0.00% 抖动: 0.00% 解码: 1.25 ms 帧队列: 0.50 ms`。

- 使用客户端电脑的本地时间，24 小时制，时、分、秒均补足两位。
- 标签统一使用英文冒号，冒号后一个英文空格；同行各组信息之间一个英文空格，
  整段及各行首尾不留空格。完整模式保留原有换行结构。
- 开启性能统计即可显示，无需新增设置；`Ctrl+Alt+Shift+S` 切换显示，
  `Ctrl+Alt+Shift+A` 切换完整／精简模式。
- 时间随视频统计约每秒刷新；停止接收视频时暂缓刷新，恢复后读取当前时间。
- 保留原有字体、背景和居中方式；退出串流时的统计日志同步规范标点和空格，
  但不加入时间前缀。

Windows 安装包仍使用 `6.2.0.0`，支持同版本覆盖安装。退出正在运行的客户端后
运行新安装包；若使用自定义安装目录，请选择原目录。安装后可运行同目录下的
`Test-AxixiInstallation.ps1`，使用更新后的清单验证安装的程序是否为本次构建。

实机验收：检查完整／精简模式的开头时间、秒数更新、前导零、跨午夜显示，
以及隐藏后重新显示和模式切换。自动构建及现有回归测试不能替代串流画面验收。
